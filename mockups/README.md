## 2. 需要实现截图时，现场拍

```powershell
# 1) 造样本数据（122 项目 / 319 送样），落在 .verify_fixture\
.venv\Scripts\python.exe tools\make_fixture_data.py

# 2) 拍主界面：输出路径 宽 高 延时ms 视图 展开第几张( -1 = 不展开) 主路径 [子窗口]
.venv\Scripts\python.exe tools\render_main_window.py .verify_shots\cards.png 1280 800 5000 cards -1 .verify_fixture
.venv\Scripts\python.exe tools\render_main_window.py .verify_shots\settings.png 1280 800 5000 cards -1 .verify_fixture settings
```

- 参数含义见 `tools\render_main_window.py --help`
- 子窗口可选 `settings` / `stats` / `new`；抓图走 `PrintWindow`（窗口自己往内存 DC 重画），
  所以子窗口被主窗口遮住也拍得出来；代价是对话框丢了系统投影，图里外圈会有一圈黑边
- 本机 DPI 缩放是 125%，按 1280x800 拍会超出客户区（实际只有 1056x699）。要拍整屏就在跑之前
  把 tk scaling 钉回 1.0（`root.tk.call("tk", "scaling", 96.0/72.0)` 并让 `self._scale` 保持 1.0），
  代价是截图里字号偏小
- 想用真实数据拍，把最后一个路径参数换成真实主路径即可（例如数据盘上的实际项目根目录）
