### 1.5 界面美化与效率优化（2026-09-30）

三个新模块：`ui/theme.py`（配色 / 字体 / ttk 样式集中一处）、`ui/widgets.py`（圆角自绘控件）、
`runtime/dpi.py`（DPI 感知与缩放）。

| 项 | 位置 | 说明 |
| --- | --- | --- |
| 字体统一 | `ui/theme.py` `create_theme()` | 界面代码里硬编码的是 `("Segoe UI", …)`，而 Segoe UI 没有中文字形，中文只能逐字回退到别的字体，同一行里字重/字宽/行高都不一致。改为统一的 CJK 家族（按可用性回退：Microsoft YaHei UI → Microsoft YaHei → PingFang SC → Noto Sans SC → Segoe UI），并把 Tk 的命名字体一并改掉 —— messagebox、下拉列表、菜单也跟着变 |

| DPI 感知 | `runtime/dpi.py` | 建窗之前声明进程 DPI 感知，再按 `winfo_fpixels('1i')` 设 `tk scaling`；高 DPI 下文字不再被系统重采样发虚。100% 缩放（本机 96 DPI）下像素常量与窗口尺寸都不变 |
| 圆角 + 阴影 | `ui/widgets.py` `RoundedPanel` / `RoundedButton` / `SegmentedControl` | Tk 画不出圆角：面板/按钮/分段控件全部画在 Canvas 上（`create_polygon(smooth=True)` + 多层偏移浅色多边形做柔和阴影）。分段控件取代原来两个并排按钮当视图开关 |

**效率：改了什么、以及实测确认"不改"的**

| 项 | 实测 | 处理 |
| --- | --- | --- |
| 按钮里的 📊（U+1F4CA） | Tk 首次为它做系统字体回退匹配要 **830–900 ms** —— 占冷启动 60%（进程→窗口可见 1393 ms → 444 ms） | **去掉 emoji**，改成画布上自绘的矢量小图标（三根圆角柱子，无字体依赖）。启动 **1393 ms → 470 ms** |
